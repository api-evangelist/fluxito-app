Fluxito provides marketing analytics integration for AI platforms, connecting Google Analytics, Google Tag Manager, Google Ads, Meta, TikTok, Snap, and BigQuery to AI-driven workflows. It offers live dashboards, MCP-ready data streams, and tools to reduce busywork in marketing data pipelines, enabling better decision‑making and campaign optimization across multiple ad networks.

**Areas:** Company · Marketing · Analytics · AI · Integration · SaaS

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Fluxito: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
